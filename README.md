# NotchTOP — archivio delle release

Qui non c'è codice. Questo repository serve solo a conservare i file `.dmg` di
[NotchTOP](https://notchontop.vercel.app), l'app che rende utile il notch dei Mac.

L'app si aggiorna da sola con [Sparkle](https://sparkle-project.org): legge
l'elenco delle versioni da
[`appcast.xml`](https://notchontop.vercel.app/appcast.xml) e scarica il `.dmg`
dalla release corrispondente che trovi qui a fianco.

Ogni release ha il nome della versione (`v1.4.5`) e un solo allegato
(`NotchTOP-1.4.5.dmg`). I tag puntano tutti al primo commit di questo
repository: non c'è una storia da seguire, ci sono solo file da non perdere.

**Per scaricare NotchTOP** vai su <https://notchontop.vercel.app> — è la strada
comoda, con le istruzioni di installazione.
